# Yize Zhao team · Pipeline collection

[Visit the public showcase](https://github.com/Zhao-team?view_as=public) · [Browse all pipelines](PIPELINES.md)

This repository maintains the group's public pipeline collection. Project code stays in its existing repository, including repositories maintained by individual authors.

## Add or update a pipeline

1. Add the tool to the relevant category in `PIPELINES.md`, with its purpose, language, original code link, and paper citation.
2. Link a working example or getting-started guide when available. If code is available only in a journal supplement, label that clearly and link to the source.
3. For a featured tool, update `profile/README.md`. The `flow-*.svg` files provide the overview's workflow illustrations.

Keep authorship, citations, and original source links intact. Link a tagged release or archived version when the paper has a fixed code release. Shared links avoid maintaining duplicate copies of a member's repository.

Members can suggest changes through a pull request or an issue.

For questions about a particular pipeline, use its source repository's issues and contribution guidance.
